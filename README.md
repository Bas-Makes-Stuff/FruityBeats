# FruityBeats

Independent music workstation development builds for Windows and Apple Silicon macOS.

## Downloads

Open [Releases](https://github.com/Bas-Makes-Stuff/FruityBeats/releases) and download the named asset for your system:

- **FruityBeats-Windows.zip** — contains `FruityBeats.exe` and a categorized `Sounds` folder. Windows 10/11 with .NET Framework 4.8.
- **FruityBeats-macOS.app.zip** — contains `FruityBeats.app` and the same `Sounds` folder. Apple Silicon only, macOS 15 or newer. The runtime is bundled.

Both packages include 347 original WAV samples in Drums, Bass, Keys, Leads, Pads and FX. Download the named release assets rather than GitHub's automatically generated source-code archives.

## Current status

Windows 1.5 passes 82 acceptance checks. The Mac build is a **development preview**: cross-publishing and package structure/checksums pass, and its shared engine and frontend checks pass on Windows. Native Mac launch, audio, devices and full feature parity are still being tested. The applications are unsigned; no signing/notarization claim is made.

The full DAW feature set and matching Windows/Mac workflows remain in development. Each ZIP includes documentation describing its current scope and limitations.

FruityBeats is independent software and is not affiliated with Image-Line. Its synthesis and sound library contain no third-party recordings.
